## ✨ المميزات

- 🎯 توليد كلمات مرور عشوائية باستخدام وحدة `secrets` (آمنة تمامًا)
- 🎨 واجهة نصية ملوّنة مع شعار ASCII احترافي
- ⚙️ تخصيص كامل:
  - طول كلمة المرور
  - تضمين أحرف كبيرة `A-Z`
  - تضمين أحرف صغيرة `a-z`
  - تضمين أرقام `0-9`
  - تضمين رموز خاصة `!@#$%^&*...`
- 📊 عرض تقييم قوة كلمة المرور (ضعيفة، متوسطة، قوية، قوية جدًا)
- 🖥️ تعمل على ويندوز، لينكس، وماك بدون أي تعديلات
- 📦 لا تحتاج إلى تثبيت أي مكتبات خارجية
