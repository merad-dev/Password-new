## ✨ Features

- 🎯 Generates random passwords using the `secrets` module (cryptographically secure)
- 🎨 Colorful text-based interface with an ASCII logo
- ⚙️ Full customization:
  - Password length
  - Include uppercase letters `A-Z`
  - Include lowercase letters `a-z`
  - Include digits `0-9`
  - Include special symbols `!@#$%^&*...`
- 📊 Displays password strength rating (Weak, Medium, Strong, Very Strong)
- 🖥️ Cross-platform: Windows, Linux, macOS
- 📦 Zero external dependencies
